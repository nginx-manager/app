# 8. 버전 이력과 롤백

적용, 롤백, 인증서 발급·갱신처럼 설정이 바뀔 때마다 그 시점의 모든 설정 파일이 **버전**으로 남습니다. **버전 이력** 메뉴에서 봅니다(관리자). 멤버가 적용한 변경도 버전으로 남고, 롤백은 관리자가 합니다. 사이트 하나의 이력은 사이트 화면의 **변경 이력**으로 봅니다(멤버도, 아래 [사이트별 이력](#사이트별-이력)).

## 버전 목록

<p align="center"><img src="images/versions.png" alt="변경 이력" width="860"></p>

| 칸 | 내용 |
| --- | --- |
| 버전 | 버전 번호. 누르면 그 버전의 화면이 열립니다. |
| 시각, 작성자 | 언제 누가 바꿨는지. 인증서 자동 갱신처럼 사람이 하지 않은 변경은 **시스템**입니다. |
| 종류 | 초기 가져오기, 적용, 롤백, 드리프트 가져오기, 인증서 발급, 인증서 갱신 |
| 결과 | 적용됨, nginx -t 실패, 자동 롤백 |
| 메모 | 적용할 때 적은 변경 메시지 |
| 파일 | 바뀐 파일 수 |

## 사이트별 이력

사이트 화면 제목 옆의 **변경 이력**을 누르면 그 사이트가 바뀐 버전만 보입니다(v1.2.4부터). 관리자는 버전 이력 화면 위의 **사이트 도메인**에 도메인을 적고 **필터**를 눌러도 됩니다. 지운 사이트도 도메인으로 찾습니다.

- 보이는 버전: 사이트 파일(켜짐·꺼짐)이나 Basic 인증 파일의 내용이 바로 앞 버전과 달라진 버전(만들기, 고치기, 켜고 끄기, 지우기, 인증서 경로 바꾸기)과, 그 파일을 적용하려다 실패한 버전.
- 필터한 목록에서 버전을 열거나 두 버전의 diff를 보면 그 사이트의 파일만 보입니다. **전체 버전 이력**으로 돌아갑니다.
- **멤버**는 담당 사이트의 이력만 봅니다. 버전 화면과 diff에도 담당 사이트의 파일만 보이고, 롤백 버튼과 드리프트 알림은 보이지 않습니다.

## 두 버전 비교

1. **base** 칸에서 기준 버전을, **compare** 칸에서 비교할 버전을 고릅니다. 처음에는 최근 두 버전이 골라져 있습니다(바로 앞 버전이 base, 가장 최근 버전이 compare).
   - base는 compare보다 앞선 버전만 고를 수 있어, 그렇지 않은 버튼은 흐리게 막혀 있습니다. 더 최근 버전을 base로 고르려면 compare를 먼저 옮기세요.
2. **선택한 두 버전 비교**를 누릅니다.

파일마다 추가·삭제·수정이 표시되고, base 버전에서 compare 버전으로 바뀐 내용이 diff로 보입니다. 실패한 버전은 적용하려던 파일만 담고 있어 그 파일들만 비교합니다.

## 이전 버전으로 롤백

1. 이력에서 돌아갈 버전을 눌러 버전 화면을 엽니다. 그 시점의 설정 파일이 모두 보입니다.
2. **이 버전으로 롤백**을 누릅니다.

롤백도 적용과 같이 nginx -t → reload → 헬스 체크를 거치고, 그 결과를 **새 버전**으로 기록합니다. 기존 이력은 지워지지 않으므로 롤백을 다시 롤백할 수도 있습니다.

<p align="center"><img src="images/version-detail.png" alt="버전 화면과 롤백 버튼" width="860"></p>

옛 인증서를 쓰던 버전으로 롤백할 때: 인증서를 갱신하면 오래된 인증서 파일은 정리됩니다([9장](09-certs.md#자동-갱신)). 롤백할 버전이 이미 지워진 인증서 파일을 가리키면, 같은 인증서의 지금 파일 경로로 바꿔 적용합니다. 인증서 자체를 지웠다면 경로를 바꾸지 않으므로 nginx -t에서 실패하고 반영되지 않습니다.

롤백할 수 없는 경우:

- 적용 대기 중인 변경이 있으면 롤백하지 않습니다. 적용 화면에서 먼저 적용하거나 취소합니다.
- nginx -t 실패·자동 롤백으로 끝난 버전은 전체 설정을 담고 있지 않아 롤백 대상으로 쓸 수 없습니다.
- 서버의 설정이 이미 그 버전과 같으면 바꿀 것이 없다고 알려 줍니다.

## 서버에서 직접 바뀐 설정

누군가 서버에서 설정 파일을 직접 고치면(드리프트), 관리도구가 마지막으로 적용한 내용과 디스크의 파일이 달라집니다. 이를 감지하면 모든 화면 위에 "드리프트: 서버에서 직접 바뀐 설정 파일이 N개 있습니다" 띠가 나타나고, 버전 이력 화면 위에 바뀐 파일(바뀜, 새 파일, 사라짐)이 보입니다.

두 가지 중 하나를 고릅니다.

- **바뀐 내용을 받아들이기**: **지금 상태를 새 버전으로 가져오기**를 누릅니다. 디스크의 파일은 그대로 두고 지금 내용을 새 버전(**드리프트 가져오기**)으로 기록해, 이후 이력과 롤백의 기준으로 삼습니다.
- **바뀐 내용을 버리기**: 가져오지 말고, 원하는 이전 버전으로 롤백합니다.

## 버전이 차지하는 공간

버전은 지우지 않고 모두 남습니다. 대신 파일 내용은 한 번만 저장해, 바뀌지 않은 파일은 이전 버전과 같은 내용을 가리킵니다. 사이트가 많아도 버전 하나가 늘리는 크기는 그 버전에서 바뀐 파일만큼입니다. v1.2.4로 올리면 처음 시작할 때 기존 이력의 같은 내용을 하나로 합치고 DB 파일(`data/manager/nginx-manager.db`)을 줄입니다. 이력이 많으면 이 시작이 조금 더 걸립니다.
