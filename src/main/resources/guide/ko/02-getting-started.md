# 2. 처음 시작하기

## 최초 관리자 계정 만들기

설치한 뒤 `http://<서버 주소>:9000`에 처음 접속하면 **관리자 계정 만들기** 화면이 나옵니다. 이 화면은 등록된 사용자가 하나도 없을 때만 나타납니다.

1. 아이디를 적습니다. 영문, 숫자, `.` `_` `-`만 쓸 수 있습니다.
2. 비밀번호를 10자 이상으로 두 번 적습니다.
3. **만들기**를 누르면 로그인 화면으로 넘어갑니다.

이 계정은 관리자 역할을 가지며, 다른 사용자를 추가하고 권한을 줄 수 있습니다([12장](12-admin.md#사용자)). 비밀번호를 잃어버리면 되찾을 방법이 없으니 안전한 곳에 보관하세요.

## 로그인

아이디와 비밀번호로 로그인합니다.

- 5번 연속 틀리면 계정이 10분 동안 잠깁니다. 시간이 지나면 저절로 풀립니다.
- 비밀번호를 잊었다면 관리자에게 재설정을 요청합니다.
- 관리자가 내 역할을 바꾸거나 비밀번호를 재설정하면 바로 로그아웃되고, "계정 정보가 바뀌어 로그아웃됐습니다"라는 안내가 나옵니다.
- 왼쪽 소개 패널의 로고 옆에 관리도구 버전이, 아래에 **GitHub** 링크(저장소)가 있습니다.

## 화면 구성

<p align="center"><img src="images/dashboard.png" alt="로그인한 뒤의 대시보드" width="860"></p>

- **왼쪽 메뉴**: 대시보드, 사이트, 스트림, 설정 파일, 버전 이력, 인증서, 적용이 있습니다. 관리자에게는 **관리** 아래에 사용자, 감사 로그, 설정이 더 보입니다. 멤버에게는 대시보드, 사이트, 적용만 보입니다([역할](README.md#역할)). 메뉴 아래 테두리가 있는 **사용 설명서** 버튼은 관리도구 안에서 이 설명서를 엽니다(v1.2.0부터). 적용 메뉴 옆의 숫자는 적용 대기 중인 변경 수입니다.
- **언어**: 메뉴 아래에서 한국어, English, 日本語, 简体中文 중에 고릅니다. 고른 언어는 브라우저에 기억됩니다.
- **테마 바꾸기**: 밝은 화면과 어두운 화면(다크 모드)을 바꿉니다. 처음에는 운영체제 설정을 따릅니다.
- **내 계정과 로그아웃**: 메뉴 맨 아래의 아이디를 누르면 [내 계정](#내-계정)으로 갑니다. 그 아래 **로그아웃**이 있습니다.
- **경고 띠**: nginx 컨테이너에 연결할 수 없거나 두 컨테이너의 버전이 다르면, 또는 서버에서 설정 파일이 직접 바뀌었으면 화면 위에 띠가 나타납니다([13장](13-troubleshooting.md)).
- **footer**: 화면 맨 아래에 GitHub 아이콘과 관리도구 버전(`manager v1.2.0`), nginx 버전(`nginx 1.31.8`), **사용 설명서** 링크가 있습니다. 관리도구 버전을 누르면 GitHub에서 그 버전의 릴리스 노트가 열리고, 사용 설명서를 누르면 이 설명서로 갑니다. 왼쪽 위 로고 옆에도 관리도구 버전이 보입니다.

### 휴대폰에서

화면 폭이 좁으면 왼쪽 메뉴가 오른쪽 위의 메뉴 버튼(≡) 안으로 들어갑니다. 버튼을 눌러 메뉴를 엽니다. 적용 대기 수는 버튼에도 보입니다. 표와 Raw 설정은 상자 안에서만 가로로 밀어 봅니다.

## 사용 설명서

이 설명서는 관리도구 안에서 봅니다(v1.2.0부터). 왼쪽 메뉴의 **사용 설명서**나 footer의 링크를 누르면 열리고, 인터넷이 막힌 망에서도 보입니다.

- **왼쪽 차례**: 모든 장이 있고, 지금 보는 장이 표시됩니다.
- **가운데 본문**: 장 안의 다른 장 링크를 누르면 그 장의 해당 부분으로 갑니다.
- **이 장의 내용**: 넓은 화면에서는 오른쪽에 지금 장의 소제목이 보여 장 안을 빠르게 오갑니다.
- **이전·다음**: 장 끝에서 앞뒤 장으로 넘어갑니다.
- 휴대폰에서는 차례가 본문 위에 접혀 있고, **차례**를 누르면 펼쳐집니다.
- 영어·일본어·중국어 화면에서는 메뉴와 차례 이름이 그 언어로 보이고, 본문은 한국어로 보입니다.

<p align="center"><img src="images/guide.png" alt="관리도구 안의 사용 설명서 화면" width="860"></p>

## 내 계정

메뉴 맨 아래의 내 아이디를 누르면 비밀번호를 바꾸는 화면이 나옵니다.

1. 현재 비밀번호를 적습니다.
2. 새 비밀번호를 10자 이상으로 두 번 적습니다. 여러 단어를 이은 긴 문구가 외우기 쉽고 안전합니다.
3. **변경**을 누릅니다.

관리자가 처음 정해 준 비밀번호로 로그인했다면 여기서 바로 바꾸세요.
