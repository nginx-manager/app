# 9. 인증서

**인증서** 메뉴에서 HTTPS 인증서를 한곳에서 봅니다. Let's Encrypt로 받은 인증서와 직접 올린 인증서가 함께 보입니다.

<p align="center"><img src="images/certs.png" alt="인증서 목록" width="860"></p>

| 칸 | 내용 |
| --- | --- |
| 이름 | 인증서 이름. Let's Encrypt 인증서는 사이트의 대표 도메인입니다. |
| 도메인 | 인증서에 들어 있는 도메인 |
| 출처 | Let's Encrypt 또는 업로드 |
| 상태 | 발급 중, 대기, 정상, N일 남음, 실패 N회 |
| 만료, 다음 갱신 | 만료일과 다음 자동 갱신 시각 |
| 사용 사이트 | 이 인증서를 쓰는 사이트 |

## Let's Encrypt 인증서 받기

사이트를 만들 때 HTTPS에서 Let's Encrypt를 고르는 것이 가장 쉽습니다([4장](04-sites.md#https)). HTTPS 없이 만든 사이트는 이 화면의 **Let's Encrypt 인증서 받기**에서 사이트를 고르고 **발급받기**를 누릅니다.

- 사이트의 대표·추가 도메인이 모두 한 인증서에 들어갑니다.
- 도메인이 이 서버를 가리키고 인터넷에서 80 포트로 들어올 수 있어야 합니다(HTTP-01 인증).
- 아직 적용하지 않았거나 꺼 둔 사이트는, 적용할 때(꺼 둔 사이트는 켜고 적용할 때) 발급을 시작합니다.
- 발급되면 사이트 설정에 HTTPS가 자동으로 적용되고 이력에 **인증서 발급** 버전이 남습니다.

## 자동 갱신

Let's Encrypt 인증서는 **다음 갱신** 시각에 저절로 갱신됩니다. 관리도구는 6시간마다 갱신할 인증서를 찾습니다.

- 갱신된 인증서는 새 경로(`/etc/nginx/certs/<이름>/<시각>/`)에 쓰고 설정의 경로만 바꿔 적용하므로, 인증서 교체도 이력에 남고 되돌릴 수 있습니다.
- 갱신에 실패해도 지금 인증서로 계속 서비스합니다. 실패 횟수와 다음 시도 시각이 목록에 보이고, [알림 설정](12-admin.md#알림-설정)의 채널로 알립니다.
- 바로 갱신하려면 **지금 갱신**을, 실패한 인증서는 **다시 시도**를 누릅니다. 멤버는 담당 사이트 화면의 HTTPS 칸에서 같은 단추를 씁니다.

## 인증서 업로드

와일드카드 인증서나 사내 CA 인증서처럼 직접 받은 인증서를 올립니다(관리자).

1. **이름**을 적습니다. 영문, 숫자와 `.` `_` `*` `-`만 씁니다(예: `wildcard.example.com`). 같은 이름으로 올리면 교체합니다.
2. **인증서 체인 (PEM)**: 서버 인증서를 맨 앞에 두고 중간 인증서를 순서대로 이어 붙인 파일을 고릅니다.
3. **개인 키 (PEM)**: 암호가 걸리지 않은 키를 고릅니다. nginx는 시작할 때 암호를 입력받을 수 없습니다.
4. **올리기**를 누릅니다.

관리도구가 키와 인증서가 맞는지, 이미 만료되지 않았는지 확인합니다. 올린 인증서를 쓰려면 사이트 설정의 HTTPS에서 **업로드한 인증서 사용**을 고르고 이 인증서를 선택한 뒤 초안을 저장·적용합니다. 업로드한 인증서는 자동으로 갱신되지 않으니, 만료 전에 같은 이름으로 다시 올립니다. 만료가 가까워지면 대시보드와 알림으로 알려 줍니다.

## Let's Encrypt 설정

인증서 화면 위의 **Let's Encrypt 설정**에서 정합니다(관리자).

<p align="center"><img src="images/acme.png" alt="Let's Encrypt 설정" width="860"></p>

- **환경**: **스테이징**(시험용, 브라우저가 신뢰하지 않음)과 **운영**(실제 인증서). 운영 환경은 같은 도메인의 발급 횟수 제한이 엄격하니, 처음에는 스테이징으로 발급이 되는지 확인한 뒤 운영으로 바꿉니다.
- **연락용 메일**(선택): ACME 계정에 등록되어 Let's Encrypt의 만료 안내를 받습니다. 비워도 발급에는 문제가 없습니다.
- 서버의 `NGINX_MANAGER_ACME_DIRECTORY_URL`이 정해져 있으면 그 주소가 이 선택보다 우선한다고 화면에 표시됩니다.
