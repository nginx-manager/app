# 3. 대시보드

로그인하면 처음 보이는 화면입니다. nginx가 잘 돌고 있는지, 해야 할 일이 남았는지를 한눈에 봅니다.

<p align="center"><img src="images/dashboard.png" alt="대시보드" width="860"></p>

## 위쪽 요약

멤버에게는 본인이 담당한 사이트의 수와 그 사이트 인증서의 경고만 보이고, 최근 적용과 DB 크기는 보이지 않습니다.

| 칸 | 내용 |
| --- | --- |
| nginx | 실행 중인지, nginx 버전 |
| 활성 사이트 | 켜 둔 사이트 수와 전체 사이트 수 |
| 적용 대기 | 적용 대기 중인 변경 수. 0이면 "모두 적용됨"입니다. [적용](07-apply.md) 화면에서 적용합니다. |
| 인증서 경고 | 만료가 가깝거나 발급·갱신에 실패한 인증서 수 |

## nginx 상태

nginx의 실행 상태와 버전, 마지막 재시작 시각, 마스터 PID, 관리도구와 nginx 컨테이너의 버전, 사이트 수, 관리도구 DB 크기를 보여 줍니다. 관리도구와 nginx 컨테이너는 따로 업그레이드하므로 두 버전이 달라도 정상입니다.

[관리 도메인](01-install.md#관리-도메인으로-https-열기)을 쓰면 **관리 화면 도메인**에 그 도메인과 상태(HTTPS, 인증서를 기다리는 중, 같은 도메인의 사이트가 있음)가 보입니다(관리자, v1.2.0부터).

nginx가 멈춰 있으면 **nginx 시작** 버튼이 나타납니다. 설정을 고쳐 적용한 뒤 이 버튼으로 nginx를 다시 띄웁니다(관리자).

## 인증서 확인 필요

만료가 가깝거나 발급·갱신에 실패한 인증서가 있으면 이 칸에 보입니다. 이름을 누르면 [인증서](09-certs.md) 화면으로 갑니다.

## 최근 적용

최근에 적용·롤백·인증서 발급으로 바뀐 버전 몇 개를 보여 줍니다. **전체 버전 이력**을 누르면 [버전 이력](08-versions.md) 화면으로 갑니다.

## 설치된 모듈

이 nginx 이미지에 들어 있는 모듈과 각 모듈이 하는 일을 보여 줍니다. 처음에는 접혀 있고, 제목을 누르면 펼칩니다.

- 괄호 안은 설정에서 그 모듈을 쓸 때 적는 대표 지시어입니다(예: `auth_request`, `sub_filter`).
- **동적** 표시가 붙은 모듈은 `load_module`로 불러와야 쓸 수 있습니다.
- 폼에 없는 모듈은 [설정 파일](10-files.md)에서 직접 설정합니다.

## 업그레이드 뒤 시작 검사에 실패했을 때

nginx 이미지를 바꾼 뒤 새 nginx가 지금 설정을 받아들이지 않으면, nginx를 띄우지 않고 대시보드 맨 위에 **nginx를 띄우지 않았습니다: 시작 검사 실패**가 나타납니다. 문제가 된 파일과 줄, 이전/현재 nginx 버전, 복구 방법이 함께 보입니다. 자세한 방법은 [13장](13-troubleshooting.md#업그레이드-뒤-nginx가-뜨지-않을-때)에 있습니다.
