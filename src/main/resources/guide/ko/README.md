## 한눈에 보기

nginx manager는 nginx 설정을 **초안 → 검증 → 적용** 순서로만 바꿉니다.

1. 사이트·스트림·설정 파일 화면에서 바꾼 내용은 먼저 **초안**으로 저장됩니다. 이때 nginx는 아무것도 바뀌지 않습니다.
2. **적용** 화면에서 바뀔 내용을 diff로 확인하고 **검증 후 적용**을 누릅니다.
3. 관리도구가 `nginx -t`로 문법을 검사하고, 통과하면 reload한 뒤 nginx 상태를 확인합니다. 문법이 틀리면 아무것도 바꾸지 않고, reload 뒤 상태가 나쁘면 직전 설정으로 저절로 되돌립니다.
4. 적용할 때마다 그 시점의 모든 설정 파일이 **버전**으로 남아, 언제든 비교하고 되돌릴 수 있습니다.

## 역할

사용자마다 두 역할 중 하나를 가집니다(v1.2.0부터). 화면과 메뉴는 역할에 맞게 보입니다.

| 역할 | 할 수 있는 일 |
| --- | --- |
| 멤버 | 본인이 **담당한 사이트만** 보고, 만들고, 고치고, 켜고 끄고, 로그를 보고, HTTPS(Let's Encrypt)를 켜고, 적용합니다. 새로 만든 사이트는 본인이 담당합니다. 적용 화면에도 본인 사이트의 변경만 보이고, 적용하면 그 변경만 반영됩니다. |
| 관리자 | 모든 사이트와 기능을 관리합니다. 사이트마다 [담당 멤버를 정하고](04-sites.md#사이트-담당자), 스트림·설정 파일·가져오기·이력과 되돌리기·인증서·사용자·감사 로그·설정을 다룹니다. |

여러 사이트에 걸치거나 서버 전체에 영향을 주는 기능(설정 파일 원문, 스트림, 설정 파일 가져오기, 이력과 되돌리기, 인증서 화면, 사용자, 감사 로그, 설정)은 관리자만 씁니다.

v1.1 이전의 **편집자**와 **보기 전용** 사용자는 v1.2.0으로 올리면 **멤버**가 됩니다. 올린 직후에는 기존 사이트에 담당자가 없어 멤버에게 사이트가 보이지 않으니, 관리자가 사이트마다 담당자를 정해 줍니다.
