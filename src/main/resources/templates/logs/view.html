access error

사이트별 로그를 남기는 초안을 만들었습니다. 적용 화면에서 반영하세요.

적용하면 이 파일에 남습니다: /var/log/nginx/sites/app.local.access.log 적용 화면

이 사이트의 원문 설정에 access_log가 없어 공통 로그(/var/log/nginx/access.log)에 다른 사이트와 함께 쌓입니다.

이 사이트의 원문 설정이 로그를 끄고 있습니다(access_log off).

원문 설정의 로그 경로를 파일 하나로 읽을 수 없습니다(변수, syslog 등): syslog:server=…

원문 설정의 로그 경로가 로그 디렉터리(/var/log/nginx) 밖이라 읽지 않습니다: /srv/app.log

server 블록에 access_log, error_log 두 줄을 더한 초안을 만듭니다.

사이트별 로그로 남기려면 관리자에게 요청하세요.

입력한 글자가 들어간 줄만 보여 줍니다.

파일: /var/log/nginx/sites/app.local.access.log

로그 파일이 아직 없습니다. 이 사이트로 요청이 들어오면 생깁니다.
