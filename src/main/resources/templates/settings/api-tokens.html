사용 예

토큰은 관리자 권한으로 동작하고 감사 로그에 token:이름으로 남습니다.

curl -H "Authorization: Bearer $NM_TOKEN" https://manager.example.com/api/v1/sites

curl -X POST -H "Authorization: Bearer $NM_TOKEN" -H "Content-Type: application/json" \
     -d '{"enabled": true, "apply": true}' \
     https://manager.example.com/api/v1/sites/app.example.com/maintenance

curl -X POST -H "Authorization: Bearer $NM_TOKEN" https://manager.example.com/api/v1/apply
