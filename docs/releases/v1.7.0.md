# v1.7.0 — 스트림 접근 제한·PROXY protocol, 백엔드 장애 안내 페이지, 사이트 목록 검색

- 날짜: 2026-10-30
- 이미지: `ghcr.io/nginx-manager/app:1.7.0`, `ghcr.io/nginx-manager/nginx:1.7.0-nginx1.31.8`
- nginx: 1.31.8 (v1.6.0과 같음)
- 설치 묶음: [GitHub Release v1.7.0](https://github.com/nginx-manager/app/releases/tag/v1.7.0)의 `install.sh`, `nginx-manager.tar.gz`

DB·SSH 같은 TCP 포트를 열 때 필요한 접근 제한, 백엔드가 멈췄을 때 방문자가 보는 화면, 사이트가 많아졌을 때 찾는 방법을 더했습니다.

## 스트림 접근 제한과 PROXY protocol

- 스트림 폼의 **허용할 주소**와 **막을 주소**에 IP나 CIDR(`10.0.0.0/8`)을 공백·쉼표·줄바꿈으로 나눠 적습니다. 허용할 주소를 적으면 그 주소만 접속할 수 있고, 막을 주소는 허용보다 먼저 봅니다.
- 접근을 제한한 스트림은 목록에 **접근 제한** 배지가 붙습니다.
- TCP 스트림은 **PROXY protocol로 클라이언트 주소 넘기기**를 켜면 백엔드에 손님의 실제 IP를 넘깁니다(`proxy_protocol on`). 백엔드가 PROXY protocol을 받도록 설정돼 있어야 합니다(사용 설명서 6장).

## 백엔드 장애 안내 페이지

- 리버스 프록시·PHP 사이트 옵션의 **백엔드 장애 안내 페이지**에서 **백엔드 장애 때 안내 페이지 보여 주기**를 켜면 백엔드가 응답하지 않을 때(502, 504) nginx 기본 오류 화면 대신 안내 페이지를 보여 줍니다. 문구는 바꿀 수 있습니다.
- 백엔드가 직접 보낸 오류 응답은 그대로 전달합니다. gRPC 사이트에는 붙지 않습니다(사용 설명서 4장).

## 사이트 목록 검색

- 사이트 목록 위에서 도메인이나 대상(백엔드 주소, 디렉터리)으로 찾고, 상태(활성, 비활성, 적용 대기, 점검 중)로 거를 수 있습니다. 멤버도 자기 사이트 안에서 씁니다.

## 업그레이드할 때

- `sudo /opt/nginx-manager/nm upgrade`로 manager만 올리면 됩니다. 에이전트 API 판은 그대로(1)라 nginx 이미지는 올리지 않아도 됩니다.
- 스트림 접근 제한을 저장할 칸이 생겨 DB 마이그레이션(V13)이 시작할 때 자동으로 적용됩니다. 기존 사이트·스트림의 설정 파일은 바뀌지 않습니다.
