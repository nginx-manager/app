# v1.4.0 — 로그인 2단계 인증, PHP·gRPC 사이트와 외부 인증(SSO), 자동 백업

- 날짜: 2026-10-30
- 이미지: `ghcr.io/nginx-manager/app:1.4.0`, `ghcr.io/nginx-manager/nginx:1.4.0-nginx1.31.8`
- nginx: 1.31.8 (v1.3.0과 같음)
- 설치 묶음: [GitHub Release v1.4.0](https://github.com/nginx-manager/app/releases/tag/v1.4.0)의 `install.sh`, `nginx-manager.tar.gz`

관리 화면 로그인에 인증 앱(TOTP) 2단계 인증을 켤 수 있고, PHP-FPM 사이트와 gRPC 프록시, oauth2-proxy·Authelia 같은 SSO 앞단(auth_request)을 Raw 설정 없이 폼으로 만듭니다. 서버는 매일 자동으로 백업하고, 대시보드에서 마지막 백업을 확인합니다. 화면 문구와 설명서도 nginx를 쓰는 개발자가 평소에 쓰는 말(적용 대기, Raw 설정, 업스트림, 롤백 등)로 정리했습니다.

## 로그인 2단계 인증

- **내 계정 → 2단계 인증 → 켜기**에서 인증 앱(Google Authenticator, Microsoft Authenticator, 1Password 등)으로 QR 코드를 찍고 6자리 코드를 넣으면 켜집니다. 이때 한 번만 보이는 복구 코드 10개를 적어 둡니다.
- 켠 뒤에는 비밀번호 다음에 코드 화면이 나오고, 코드를 넣기 전에는 다른 화면을 열 수 없습니다. 틀린 코드도 비밀번호와 같은 5번/10분 잠금에 셉니다.
- 휴대폰을 잃으면 복구 코드로 들어오거나, 관리자가 사용자 화면에서 **2단계 인증 해제**를 누릅니다. 관리자가 혼자라면 서버에서 `sudo /opt/nginx-manager/nm reset-2fa 아이디`로 끕니다(사용 설명서 2장 "2단계 인증", 13장).

## PHP (PHP-FPM) 사이트

- 사이트 유형에 **PHP**가 생겼습니다. document root와 PHP-FPM 주소(`127.0.0.1:9000`, `unix:/run/php/php8.3-fpm.sock`)만 넣으면 `try_files … /index.php?$query_string`과 `location ~ \.php$`(fastcgi_pass, SCRIPT_FILENAME)를 만듭니다. WordPress, Laravel 같은 프런트 컨트롤러가 그대로 돕니다.
- IP 제한·Basic 인증·속도 제한은 `.php` 요청에도 똑같이 걸립니다.
- 이런 모양의 기존 설정 파일은 PHP 폼 사이트로 가져옵니다(사용 설명서 4장 "PHP (PHP-FPM)").

## 외부 인증(SSO)과 gRPC 프록시

- 사이트 옵션 **접근 제한**에 **외부 인증 서버**(auth_request)와 **로그인 주소**를 넣으면, 요청마다 인증 서버에 묻고 401이면 로그인 주소로 보냅니다(`rd`에 원래 주소). 리버스 프록시는 인증 서버가 준 사용자(`X-Auth-Request-User`, `X-Auth-Request-Email`)를 백엔드로 넘깁니다.
- 리버스 프록시의 업스트림을 `grpc://호스트:포트`(TLS면 `grpcs://`)로 적으면 `grpc_pass`로 넘기고 HTTP/2로 받습니다. TLS 없이(h2c) 받으려면 그 사이트만 쓰는 HTTP 포트를 줍니다(사용 설명서 4장).

## 자동 백업

- 설치하거나 업그레이드하면 매일 03:30에 `nm backup --label auto`가 돌도록 cron(없으면 systemd 타이머)을 깝니다. 시각은 `.env`의 `NGINX_MANAGER_BACKUP_AT`(예: `04:00`, 끄려면 `off`)으로 바꾸고 `sudo /opt/nginx-manager/nm backup-schedule`을 다시 실행합니다.
- 대시보드의 **마지막 백업**에 시각·크기·자동/수동이 보이고, 실패했거나 예약했는데 48시간 넘게 백업이 없으면 경고합니다(사용 설명서 1장 "자동 백업", 3장).

## 화면 용어 정리

- 초안 → 적용 대기, 원문 편집 → Raw 설정, 프록시 대상 → 업스트림, 되돌리기 → 롤백, 비밀번호 보호 → Basic 인증처럼, 화면 문구와 설명서를 nginx·Git을 쓰는 사람이 평소에 쓰는 말로 바꿨습니다. 기능은 같습니다.

## 업그레이드할 때

- `sudo /opt/nginx-manager/nm upgrade`로 manager만 올리면 됩니다. 에이전트 API 판은 그대로(1)라 nginx 이미지는 올리지 않아도 됩니다. auth_request·gRPC·FastCGI 모듈은 지금 nginx 이미지에 이미 들어 있습니다.
- `nm upgrade`가 `.env`에 `NGINX_MANAGER_BACKUP_AT=03:30`을 더하고 자동 백업 스케줄을 깝니다. 스케줄은 root로 깔리므로 `sudo` 없이 올렸다면 `sudo /opt/nginx-manager/nm backup-schedule`을 한 번 실행합니다. 원하지 않으면 `off`로 바꿉니다.
- 처음 시작할 때 2단계 인증 열을 더하는 DB 마이그레이션(V12)을 합니다.
