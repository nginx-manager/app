# v1.1.0 — 쓰기 편한 관리 화면: 고른 유형만 보이는 사이트 폼, 대상이 보이는 사이트 목록, 접히는 적용 diff

- 날짜: 출시 예정
- 이미지: `ghcr.io/nginx-manager/app:1.1.0`, `ghcr.io/nginx-manager/nginx:1.1.0-nginx1.31.6`
- nginx: 1.31.6

> 출시 전 초안입니다. 1.1.0에 들어갈 개선을 더하면서 이 노트를 함께 고치고, 출시할 때 날짜를 적고 화면을 찍어 넣습니다.

1.0.0의 화면을 처음부터 끝까지 다시 써 보며 불편했던 곳을 다듬었습니다. 설정을 만들고 적용하는 방식은 그대로이고, 찾고 고르고 확인하는 수고가 줄었습니다. 명세는 [nginx-manager/docs](https://github.com/nginx-manager/docs)의 `specs/004-ui-usability/`에 있습니다.

## 사이트 폼은 고른 유형의 항목만 보여 줍니다

리버스 프록시를 고르면 프록시 대상과 세부 설정만, 정적 파일을 고르면 문서 루트만, 리디렉션을 고르면 보낼 주소·응답 코드만 보입니다. 리디렉션 항목은 더 이상 접힌 상자 안에 있지 않습니다. 저장할 때의 검증과 만들어지는 설정은 전과 같습니다.

## 설정 미리보기

- 유형을 바꾸자마자 다른 칸을 입력해도 미리보기가 마지막 입력까지 반영합니다.
- 넓은 화면에서는 긴 폼을 내려도 미리보기가 화면에 남습니다(사이트·스트림 추가).

## 사이트 목록에서 어디로 가는지 보입니다

새 대상 칸에 프록시는 백엔드 주소, 정적은 문서 루트, 리디렉션은 보낼 주소가 보이고, HTTPS를 켠 사이트는 포트 옆에 HTTPS가 표시됩니다. 활성/비활성과 적용 대기는 상태 칸 하나에 함께 보입니다.

## 적용 화면과 사이트 화면

- 적용 화면은 파일마다 diff를 접고 펼 수 있고, 파일 이름 옆에 더한 줄·뺀 줄 수(+17 −0)가 보입니다.
- 사이트 화면의 활성화/비활성화 버튼이 설정 원문 아래에서 제목 옆(로그 보기 옆)으로 옮겨졌습니다.
- 사용자 추가의 역할 선택이 영문 코드 대신 화면의 역할 이름으로 보입니다.

## 고친 문제

- 사이트·스트림 폼에서 앞선 미리보기 응답이 도착하며 바로 다음 입력의 미리보기 요청이 사라져, 미리보기가 비거나 예전 설정에 머물던 문제를 고쳤습니다.
- 휴대폰 폭에서 사이트·스트림 화면의 긴 설정 줄이 페이지 전체를 옆으로 밀던 문제를 고쳤습니다. 설정 원문은 상자 안에서만 가로로 스크롤됩니다.
