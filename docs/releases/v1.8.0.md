# v1.8.0 — 운영 알림, 사이트 여러 개 한꺼번에, 감사 로그 CSV

- 날짜: 2026-10-30
- 이미지: `ghcr.io/nginx-manager/app:1.8.0`, `ghcr.io/nginx-manager/nginx:1.8.0-nginx1.31.8`
- nginx: 1.31.8 (v1.7.0과 같음)
- 설치 묶음: [GitHub Release v1.8.0](https://github.com/nginx-manager/app/releases/tag/v1.8.0)의 `install.sh`, `nginx-manager.tar.gz`

관리 화면을 열어 보지 않아도 장애를 알 수 있게 알림을 넓히고, 사이트가 많을 때 반복하던 일을 줄였습니다.

## 운영 알림

- 지금까지는 인증서 발급·갱신 실패와 만료 임박만 알렸습니다. 이제 다음 일도 메일·웹훅으로 알립니다.
  - **적용 실패**: 설정 적용·롤백이 `nginx -t`에 실패했거나, 적용 뒤 상태 확인에 실패해 자동으로 되돌렸을 때
  - **nginx 내려감·재시작**: nginx 마스터 프로세스가 내려갔거나 다시 시작됐을 때
  - **직접 바뀐 설정 파일**: 서버에서 관리도구를 거치지 않고 바뀐 설정 파일을 찾았을 때. 같은 변경은 한 번만 알립니다
  - **백업 실패**: `nm backup`(자동 백업 포함)이 실패했을 때. 실패 한 번에 한 번만 알립니다
  - **계정 잠김**: 로그인 실패가 이어져 계정이 잠겼을 때
- 알림 설정 화면의 **받을 알림**에서 채널마다 받을 종류를 고릅니다. 기존 채널은 모두 받도록 그대로 둡니다(사용 설명서 12장).
- 알림은 따로 보내므로 웹훅이 느려도 적용·로그인이 기다리지 않습니다.

## 사이트 여러 개 한꺼번에

- 사이트 목록 왼쪽 칸에서 사이트를 고르고(맨 위 칸은 모두 고르기) **켜기**·**끄기**를 누르면 고른 사이트마다 초안이 생기고, 적용 화면에서 한 번에 반영합니다.
- 관리자는 **담당자 지정**으로 고른 사이트의 담당자를 한꺼번에 정합니다.
- 이미 그 상태이거나 지우는 중인 사이트는 건너뛰고, 바꾼 수와 건너뛴 수를 알려 줍니다. 검색으로 좁힌 뒤 모두 고르면 "이 백엔드를 쓰는 사이트 모두 끄기"를 한 번에 합니다(사용 설명서 4장).

## 감사 로그 CSV

- 감사 로그 화면의 **CSV 내려받기**로 지금 조건에 맞는 기록을 최근 10,000줄까지 받습니다. 엑셀에서 한글이 깨지지 않고, 수식으로 읽힐 값은 앞에 `'`를 붙여 막습니다(사용 설명서 12장).

## 업그레이드할 때

- `sudo /opt/nginx-manager/nm upgrade`로 manager만 올리면 됩니다. 에이전트 API 판은 그대로(1)라 nginx 이미지는 올리지 않아도 됩니다.
- 채널마다 받을 알림을 저장할 칸이 생겨 DB 마이그레이션(V14)이 시작할 때 자동으로 적용됩니다. 기존 채널은 새 알림까지 모두 받으니, 필요하면 알림 설정에서 줄이세요.
