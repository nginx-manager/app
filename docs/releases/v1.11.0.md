# v1.11.0 — 사이트 담당자도 추가 지시어 고치기

- 날짜: 2026-11-13
- 이미지: `ghcr.io/nginx-manager/app:1.11.0`, `ghcr.io/nginx-manager/nginx:1.11.0-nginx1.31.8`
- nginx: 1.31.8 (v1.10.0과 같음)
- 설치 묶음: [GitHub Release v1.11.0](https://github.com/nginx-manager/app/releases/tag/v1.11.0)의 `install.sh`, `nginx-manager.tar.gz`

사이트를 맡은 멤버가 `proxy_request_buffering off;` 같은 지시어 한 줄 때문에 관리자에게 부탁하지 않아도 되게 했습니다.

## 담당자도 추가 지시어를 고침

- 사이트 옵션의 **추가 지시어**(server 블록 끝에 덧붙일 nginx 지시어)를 이제 관리자뿐 아니라 그 사이트의 담당 멤버도 고치고 지울 수 있습니다. 칸 이름의 "(관리자)" 표시와 "관리자만 바꿀 수 있습니다" 안내를 뺐습니다.
- 멤버가 새로 만드는 사이트는 그 멤버가 담당자가 되므로 처음부터 추가 지시어를 넣을 수 있습니다.
- 담당하지 않는 사이트는 지금처럼 열거나 저장할 수 없습니다(404).
- 저장할 때 중괄호·따옴표 짝 검사, 적용 전 `nginx -t` 검증, 적용 diff와 감사 로그는 그대로입니다. 추가 지시어로 `location`·`alias`를 넣어 서버의 다른 경로를 내보낼 수도 있으니 믿을 수 있는 사람에게 사이트를 맡깁니다.
- Raw 편집(설정 파일 직접 편집)은 지금처럼 관리자만 씁니다.

## 업그레이드할 때

- `sudo /opt/nginx-manager/nm upgrade`로 manager만 올리면 됩니다. nginx 이미지와 에이전트 API 판(1)은 그대로이고, `.env`에서 손볼 것은 없습니다.
