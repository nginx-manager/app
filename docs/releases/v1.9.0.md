# v1.9.0 — 배포 자동화 API, 사이트 메모, 관리자 추가 지시어

- 날짜: 2026-10-30
- 이미지: `ghcr.io/nginx-manager/app:1.9.0`, `ghcr.io/nginx-manager/nginx:1.9.0-nginx1.31.8`
- nginx: 1.31.8 (v1.8.0과 같음)
- 설치 묶음: [GitHub Release v1.9.0](https://github.com/nginx-manager/app/releases/tag/v1.9.0)의 `install.sh`, `nginx-manager.tar.gz`

배포 스크립트에서 관리도구를 부를 수 있게 하고, 폼 사이트로 할 수 있는 일을 넓혔습니다.

## 배포 자동화 API

- **설정 > API 토큰**에서 관리자가 토큰을 만듭니다. 토큰 값(`nmt_…`)은 만들 때 한 번만 보이고, 관리도구에는 해시만 남습니다. 지우면 바로 막힙니다.
- `Authorization: Bearer <토큰>`으로 부릅니다.
  - `GET /api/v1/sites`: 사이트 목록(도메인, 유형, 켜짐, 점검 중, 적용 대기, HTTPS)
  - `POST /api/v1/sites/{도메인}/maintenance`: `{"enabled": true, "apply": true}`로 점검 모드를 켜고 바로 적용합니다
  - `POST /api/v1/apply`: 적용 대기 중인 변경을 모두 적용합니다
- 적용이 검증에 실패하면 `422`와 `nginx -t` 오류를 돌려주므로 `curl --fail` 한 줄로 배포를 멈출 수 있습니다.
- 토큰은 관리자 권한으로 동작하고, 한 일은 감사 로그에 `token:이름`으로 남습니다(사용 설명서 12장).

## 사이트 메모

- 사이트마다 담당 팀, 연락처, 만든 이유 같은 메모를 500자까지 남깁니다.
- 사이트 목록의 도메인 아래에 보이고 검색으로 찾을 수 있으며, 설정 파일 맨 위에 `# 메모:` 주석으로도 남습니다(사용 설명서 4장).

## 관리자 추가 지시어

- 폼에 없는 nginx 지시어를 **추가 지시어**에 적으면 server 블록 끝에 그대로 덧붙입니다. 지시어 몇 줄 때문에 사이트를 Raw 설정으로 바꾸지 않아도 됩니다.
- 저장할 때 중괄호와 따옴표의 짝을 확인하고, 내용은 적용할 때 `nginx -t`가 검증합니다.
- 관리자만 바꿀 수 있습니다. 멤버에게는 읽기 전용으로 보이고, 멤버가 사이트를 저장해도 그대로 남습니다(사용 설명서 4장).

## 업그레이드할 때

- `sudo /opt/nginx-manager/nm upgrade`로 manager만 올리면 됩니다. 에이전트 API 판은 그대로(1)라 nginx 이미지는 올리지 않아도 됩니다.
- API 토큰 표가 생겨 DB 마이그레이션(V15)이 시작할 때 자동으로 적용됩니다.
- 관리 화면 앞에 리버스 프록시를 두었다면 `/api/v1/`도 manager로 넘겨야 API를 쓸 수 있습니다.
