# v1.9.1 — 적용 화면·미리보기·삭제 대기 사이트 다듬기

- 날짜: 2026-10-31
- 이미지: `ghcr.io/nginx-manager/app:1.9.1`, `ghcr.io/nginx-manager/nginx:1.9.1-nginx1.31.8`
- nginx: 1.31.8 (v1.9.0과 같음)
- 설치 묶음: [GitHub Release v1.9.1](https://github.com/nginx-manager/app/releases/tag/v1.9.1)의 `install.sh`, `nginx-manager.tar.gz`

새 기능 없이 v1.9.0까지 나온 기능의 버그를 고치고 화면을 다듬은 버전입니다.

## 고친 문제

- **적용 화면**: **nginx -t 후 reload**로 적용에 성공해도 방금 반영한 변경이 **적용 대기 중인 변경**에 그대로 남고, 메뉴의 적용 숫자도 줄지 않았습니다. 다시 누를 수 있는 적용 버튼도 남아 있었습니다. 이제 결과와 함께 대기 목록과 메뉴 숫자가 바로 바뀝니다.
- **삭제 대기 중인 사이트**: 사이트 삭제를 누른 뒤에도 상세 화면에 저장, 비활성화, 인증서 발급 버튼이 남아 있어, 누르면 삭제 대기가 말없이 풀리고 사이트가 다시 **적용 대기**가 됐습니다. 삭제 대기 중에는 이 버튼을 감추고, 고치려면 삭제를 먼저 취소하라고 안내합니다.
- **API 토큰으로 적용한 버전**: 감사 로그에는 `token:이름`으로 남지만 버전 이력과 대시보드의 최근 적용에는 **시스템**으로 보였습니다. 이제 작성자가 `token:이름`으로 남습니다.
- **API 오류 응답**: 점검 모드 API에 본문 없이 또는 JSON이 아닌 본문을 보내면 다른 오류와 달리 `error` 칸이 없는 응답이 나갔습니다. 이제 `400`과 `{"error": "이유"}`로 알립니다.
- **스트림 추가**: 받을 포트 칸이 `0`으로 채워져 나와 지우고 다시 적어야 했습니다. 빈 칸에 예시(5432)가 보입니다.

## 화면 다듬기

- **설정 미리보기**: 사이트·스트림 추가 화면에서 입력값에 고칠 곳이 있으면(예: 관리 화면 포트 9000으로 프록시) 미리보기가 "값을 입력하면…" 안내로 돌아가 왜 비었는지 알 수 없었습니다. 이제 미리보기 자리에 고칠 곳이 보입니다.
- **사이트 화면**: 설정 파일 원문이 두 칸 중 왼쪽 칸에만 들어가 긴 줄이 잘리고 오른쪽이 비었습니다. 원문을 아래에 화면 너비로 둡니다.
- **휴대폰 화면**: 화면 아래 정보(manager 판, nginx 판, 사용 설명서)가 글자 단위로 줄이 바뀌던 것을 항목째 다음 줄로 넘깁니다.
- 사용 설명서 첫 화면의 기준 버전을 v1.9.1로 올렸습니다.

## 업그레이드할 때

- `sudo /opt/nginx-manager/nm upgrade`로 manager만 올리면 됩니다. 에이전트 API 판은 그대로(1)라 nginx 이미지는 올리지 않아도 됩니다.
- `.env`에서 손볼 것은 없습니다.
